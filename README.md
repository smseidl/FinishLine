# FinishLine

Google Sheets project containing Apps Script automation and supporting documentation.

## Folder Structure

```
FinishLine/
├── instructions/   # Prompts, notes, and context for AI-assisted development
├── scripts/        # Google Apps Script (.gs) files
└── README.md
```

## Usage

- Place `.gs` script files in the `scripts/` folder.
- Place instruction files, prompts, and notes in the `instructions/` folder.
